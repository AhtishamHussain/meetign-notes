# meetign-notes

Live meeting notes: capture Zoom, Google Meet, or any other call, turn speech into writing (English + Urdu), and save a document.

Speech models are **not** stored in this repo. Download the model onto your laptop after cloning.

## Clone

```bash
git clone https://github.com/AhtishamHussain/meetign-notes.git
cd meetign-notes
npm install
```
